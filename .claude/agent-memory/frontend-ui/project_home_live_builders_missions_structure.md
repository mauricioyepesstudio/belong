STRUCTURE SLICE DONE (2026-08-17): `engines/belong/components/home/home-live-builders.tsx` and `home-missions-row.tsx` were rebuilt to match `reference/belong-dashboard-reference.png`'s composition — layout/fallback-architecture only, no data-layer changes.

**Live Builders** (`home-live-builders.tsx` + new `home-live-builders.module.css`): each card is now a photo-dominant tile (`.mediaFrame`, ~22rem tall) with the status badge (BUILDING/NEEDS HELP/etc.) overlaid top-left, a bottom gradient scrim, and identity/description/progress-or-tag/avatar/CTA stacked on the scrim. Media priority: `activity.imageUrl` → `activity.author.avatarUrl` → branded gradient fallback (tone keyed off the existing per-type status tone, small corner icon only, never a giant centered glyph). Progress bar only renders when `activity.meta.progress` is a real number (only `project`-type activities have this per `feed-builder.ts`); otherwise falls back to `activity.contextLabel` as a tag pill — never fabricated.

**Your Missions** (`home-missions-row.tsx` + new `home-missions-row.module.css`): title now sits above an enlarged artwork frame (`.artFrame`, ~9.5rem), progress bar + next-step text below, matching the reference hierarchy. Added a `MISSION_ART_SRC` lookup (5 buckets: startup/community/growth/portfolio/default, keyed by the same keyword-matching logic the old `ART_RULES` icon picker used) pointing at `/images/missions/mission-{startup,community,growth,portfolio,default}.webp` — wired through `next/image` with a per-card `onError` → `missingArt` Set, same pattern as `WORLD_ART_SRC` in [[project-home-universe-world-art]]. None of those files exist yet, so every card currently shows the CSS fallback texture.

**Important nuance vs. [[feedback-no-stock-art-placeholder]]**: the hero world-art precedent used an *inert solid-color* fallback while waiting for the real asset. This slice's orchestrator instructions explicitly asked for something more visible instead — a restrained branded gradient + faint dot-grain texture, tone-varied per keyword bucket, deliberately kept flat/flat-blurred so it still reads as "placeholder" rather than finished art. Both are compliant with the underlying rule (no stock photos, no giant centered icons standing in for real art) — just two different fallback treatments approved for two different widgets. Don't conflate them; check which pattern a given task asks for.

**Visual-polish pass (2026-08-17, same day)**: `home-missions-row.tsx`/`.module.css` reworked from a boxed inset "artFrame + separate body" layout to a continuous atmosphere card matching the reference more closely — title now overlays the top of a full-bleed `.artStage` (flex 0 0 58% of card height) instead of sitting in its own padded row above a framed box; the per-bucket gradient+grain fallback and the future `<Image>` both share a bottom fade mask (`mask-image: linear-gradient(to bottom, #000 68%, transparent 100%)`) so real art will blend into the info panel below with no code changes needed later. Lower `.body` panel got a glass treatment (rgba dark bg + `backdrop-filter: blur(10px)` + hairline top border) to read as a distinct "premium glass" info zone per orchestrator instructions, and `GlassCard`'s existing `glow` prop (brand-purple soft shadow) was turned on for these cards — reused the existing shared primitive language rather than inventing new per-bucket shadows. `missionArtBucket()` now matches against `title + description` combined (was title-only) for more robust bucket selection; still keyword-based, still no data-contract changes. Card `min-height` went from 17.5rem to 16.5rem (kept close to prior/reference-measured ratio — reference cards measured ~158:185px width:height ≈ 0.86, very close to what was already in place, so proportions were not overhauled, just the internal layering).

**Missing assets for true final fidelity** (not attempted, out of scope for this slice):
- `public/images/missions/mission-startup.webp`, `mission-community.webp`, `mission-growth.webp`, `mission-portfolio.webp`, `mission-default.webp` — expect roughly 3:2 or 16:10 landscape illustrations (card art frame is wider than tall), thematic per bucket (rocket/launch, people/network, plant/growth, portfolio/creative), matching the reference's stylized glowing-illustration look.
- A real "avatar stack" (multiple collaborator photos) for Live Builders cards isn't possible with current data — `HomeActivity` only carries a single `author`, no participant list — so the footer shows one real avatar + comment/reaction count instead of fabricating a stack.

**Real-photo wiring + polish pass (2026-08-17, later same day)**: backend-supabase populated `activity.imageUrl` from `community_posts.image_url` / `project_posts.image_url` (`engines/belong/global-feed.ts` → `engines/belong/home/feed-builder.ts`, not touched by frontend-ui). The prior slice's media-priority chain (`activity.imageUrl` → `activity.author.avatarUrl` → gradient fallback) needed no logic changes — it "just worked." Confirmed `next.config.ts` has **no `images.remotePatterns`/`domains` configured at all** (bare config), which would block `next/image` for any external Supabase storage host; this component (and `components/ui/avatar.tsx`, the shared `Avatar` primitive) intentionally use a plain `<img>` for exactly this reason, so real photos render fine despite the empty config — not a blocker, just don't switch this to `next/image` without adding remotePatterns first.
Polish applied in `home-live-builders.tsx`/`.module.css`: (1) status badges changed from translucent-tinted pills to solid per-tone `bg-{color}-600/90 text-white`, matching the reference's solid-fill badge look (sampled reference pixel colors to confirm it's a solid fill, not glass). (2) Footer restructured from one row (avatar+meta left, small CTA right) to two stacked rows — engagement row, then a full-width CTA as an indigo-glass pill (`rgba(45,35,92,.45)` bg, hover `rgba(60,46,122,.6)`) — matches reference's "Ver proyecto"/"Ofrecer ayuda" full-width button pattern (measured/sampled from reference crop). (3) `.fallback` gradient gained a diagonal sheen layer + a `::before` dot-grain texture (`radial-gradient` 1px dots, 15px grid, `mix-blend-mode: overlay`, opacity .35) for a more premium/intentional feel per-tone — still restrained, no icons added, no fake photos. (4) `.mediaFrame` height bumped 22rem→23.5rem (19rem→20.5rem mobile) and `.scrim` stops extended (opaque zone 58%→66%) to keep the now-taller two-row footer legible against the image.
